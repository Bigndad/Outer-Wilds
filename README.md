# Outer Wilds Desktop

An interactive Outer Wilds themed desktop for Hyprland, built with Quickshell (Qt 6 / QML): a live 3D solar system as the
background, widgets orbiting the planets, and overlays (Map View, Rumor Map, Signalscope, HUD, settings).

* Run: `qs -c outerwilds` (or `ow start`). It shows on an empty workspace.
* Full documentation for humans and AI assistants: **[docs/README.md](docs/README.md)**
* Add a widget: **[WIDGETS.md](WIDGETS.md)** (or `ow new-widget <name>`)
* Working on it as an AI: **[docs/ai-guide.md](docs/ai-guide.md)**
